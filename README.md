One funny line from a hopeless tech support agent to a desperate customer —
an entry for the [Have You Tried Turning It Off?](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b)
bounty on [make.fun](https://make.fun).

> Let's turn it off and on again — I'll count to ten, you hold your breath, and we'll both pretend that's a plan.

## How it works

`main.ts` (Node 22, no dependencies) writes that single line to
`/output/entry.txt` — 111 characters, one line, inside the 1–199 character
gate. It validates the length and single-line shape first, then reads the
file back to confirm the bytes the judge scores match the line exactly.

Run it locally:

```sh
OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
